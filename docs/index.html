RM Bin

拖一张图进去，
它出现在你的 reMarkable 上。

一枚停在桌角的迷你 Paper Pro。松手的那一刻，窗口里的小屏幕和你手边的真机 同时开始落墨——同一幅画，同一个节奏。

下载 for macOS v0.3.0 · Apple Silicon · 已签名并公证 · 源码

怎么用

01

拖

把图片拖到那台小设备上。纸面会抬起来，跟着你的光标倾斜。

02

描

图像被转成笔画。你选的方式决定它是被一笔笔写下去，还是整页递过去。

03

落墨

扫描线自上而下推进——它跟的是设备的真实进度，不是计时器。

五种落墨方式

同一张图，可以用五种方式抵达设备。它们是真正不同的取舍，所以做成了设置项， 而不是藏在代码里的常量。

笔重放默认
假装成设备的笔，一笔一笔写进去。窗口里的小屏幕跟着真机同步画出同一幅——这是唯一「正在发生」的那种。内容多时要几分钟。
写入笔记本
直接生成一本新笔记送过去，几秒完成，落在干净的新页上。代价是设备要重启一次界面才能看到它。
直接显示
原图灰阶，直接推到屏幕上。最快，但不留在笔记里。
Gemini 线稿 + 笔重放
先把照片转成线稿再重放。照片直接描摹通常是一团糊，这条路让它可用。
存成 PDF
原图保真，进设备的文档库，可以在上面批注。

安静的设置

⌘, 或右键那台小设备。独立的原生窗口，改完失焦即生效，没有「保存 / 取消」。 「检查连接」会对设备的 SSH 端口做一次真实握手，告诉你往返延迟，或者到底哪一步不通。

背景是 macOS 26 的 Liquid Glass。旧系统上自动退回经典材质，不会变成一块灰板。

装它

下载 .dmg，拖进「应用程序」。App 已用 Developer ID 签名并通过 Apple 公证， 首次打开不会被拦。

设备地址在 设置 › 通用 › 关于本机 › 版权与许可 里；USB 直连时固定是 10.11.99.1。

  • macOS 11 或更新（Liquid Glass 效果需要 macOS 26）
  • Apple Silicon
  • reMarkable 2 / Paper Pro，与电脑在同一网络，或用 USB 直连

自己构建

git clone https://github.com/JIACHENG135/rm-bin
cd rm-bin
npm install
npm run tauri dev

需要 Rust 和 Node。不要用 sudo——那会把构建产物写成 root 所有，并且让 codesign 读到错误的钥匙串。
